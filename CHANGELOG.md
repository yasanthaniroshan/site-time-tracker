## [1.0.0]

### Added
- Floating card showing time spent today on YouTube and LinkedIn
- 5-minute progress bar with block counter and countdown
- Daily per-site tracking persisted in `chrome.storage.local`
- Settings page: tracked sites, block length, colour thresholds, card position, start minimized
- Compact card whose background follows the state (green / orange / red)
- Extension icons
