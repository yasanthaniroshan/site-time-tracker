# Code of Conduct

## Our pledge

We want participation in this project to be a welcoming, harassment-free
experience for everyone, regardless of age, background, experience level,
identity, or beliefs.

## Expected behavior

- Be respectful and constructive, including when you disagree
- Give and accept feedback graciously
- Focus on what is best for the project and its users

## Unacceptable behavior

- Harassment, insults, or personal attacks
- Discriminatory jokes or language
- Publishing others' private information without permission
- Any other conduct that would reasonably be considered inappropriate in a professional setting

## Enforcement

Maintainers may edit or remove comments, commits, issues, and other contributions
that violate this Code of Conduct, and may temporarily or permanently ban
contributors for behavior they deem inappropriate.

To report a problem, open a private report through the repository's
**Security → Report a vulnerability** form, or contact the maintainer through
their GitHub profile.

This Code of Conduct is adapted from the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
